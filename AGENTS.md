# OpenSpec Instructions

For requests involving proposals, specs, or significant new capabilities, read
`openspec/AGENTS.md` and `openspec/project.md` before making changes. Use the
OpenSpec proposal workflow and check existing specs and active changes first.
For routine bug fixes, documentation, and tests that preserve existing behavior,
work directly without creating a proposal.

## Reusable Skills

- Use `.github/skills/dearcygui-build/SKILL.md` when building or rebuilding
  DearCyGui, testing after `.pyx`/`.pxd` changes, or diagnosing Cython, MSVC,
  CMake, SDL3, or compiled-extension import failures.
